# زَروان | Zurvan

موشن‌گرافیک فارسی یک‌دقیقه‌ای برای پست اینستاگرام؛ تصویر نمادین و خیالی زَروان، با صدای گوینده و میان‌نویس فارسی.

## خروجی

- `deliverables/zurvan-instagram.mp4`: 1080×1080، 24fps، H.264، صدای AAC، دقیقاً 60 ثانیه
- `deliverables/cover.jpg`: تصویر کاور

## مشاهده

[دانلود ویدئوی نهایی با گویندگی و موسیقی](deliverables/zurvan-instagram.mp4) · [مشاهدهٔ کاور](deliverables/cover.jpg)

ویدئوی نهایی و کاور داخل ریپازیتوری ذخیره شده‌اند. ورودی‌های تولیدشده در `media/` برای جلوگیری از نگهداری فایل‌های اضافی در Git نادیده گرفته می‌شوند.

## ساخت دوباره

Python 3.11+:

```sh
python -m venv .venv
.venv/bin/pip install pillow numpy imageio-ffmpeg arabic-reshaper python-bidi
.venv/bin/python render.py
.venv/bin/python add_music.py
```

اسکریپت `add_music.py` یک قطعهٔ امبینت تألیفی با درونِ آرام و نت‌های زنگ‌مانند تولید می‌کند و آن را با سطح پایین زیر گویندگی میکس می‌کند. این اسکریپت را یک‌بار پس از رندر اجرا کنید؛ اجرای چندباره روی خروجی نهایی موسیقی را دوباره اضافه می‌کند.

ورودی‌ها: `media/zurvan.png` و `media/narration.wav`. فونت فارسی Vazirmatn در `assets/` قرار دارد (SIL Open Font License، پروژهٔ rastikerdar/vazirmatn).

تصویر و صدا با هوش مصنوعی تولید شده‌اند. چهرهٔ زَروان بازسازی تاریخی نیست. روایت، زَروانی‌گری را از باور همهٔ زرتشتیان متمایز می‌کند. موسیقی پس‌زمینهٔ امبینت به‌صورت برنامه‌نویسی‌شده و تألیفی تولید و با سطح پایین زیر روایت میکس شده است. این موسیقی بازسازی موسیقی ایران باستان نیست.
