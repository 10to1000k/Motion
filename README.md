# زَروان | روایتِ زمان

موشن‌گرافیک فارسی یک‌دقیقه‌ای، مربع 1080×1080، با گویندگی، موسیقی امبینت تألیفی و طراحی صوتی.

## نسخهٔ جدید: حرکت واقعی عناصر گرافیکی

[ویدئوی نهایی](deliverables/zurvan-instagram.mp4) · [کاور](deliverables/cover.jpg)

این نسخه صرفاً عکسِ زوم‌شده یا موج‌داده‌شده نیست: بخش عمدهٔ تصاویر در هر فریم از هندسه و ذرات متحرک ساخته می‌شود. از ویدئوی استوک یا فیلم اینترنتی استفاده نشده است. تصویر زَروان فقط در دو میان‌نمای کوتاه و تصویر معماری در یک میان‌نمای پنج‌ثانیه‌ای استفاده می‌شود؛ این سه میان‌نما همچنان تصویرسازی با حرکت دوربین هستند، نه ویدئوی مولد شخصیت.

## طراحی و صدا

- ذرات با مسیرهای زمان‌مند، مدارهای مستقل، بلوم نور و میدان ستاره‌ای با عمق.
- ورود نرم تایپوگرافی فارسی، خط راهنمای زمان و کات‌های کوتاه از میان تیرگی.
- موسیقی استریو با درون، نت‌های میانی و پالس آرام؛ افکت‌های گذار روی مرز صحنه‌ها.
- سایدچین موسیقی زیر گویندگی؛ نرمال‌سازی نهایی با هدف ‎−16 LUFS و سقف true peak برابر ‎−1.5 dBTP.
- خروجی H.264 / yuv420p، 24fps، AAC استریو 48kHz، مدت دقیق 60 ثانیه.

## بازتولید

تمام ورودی‌های لازم داخل `assets/` موجودند.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest test_render -v
.venv/bin/python render.py
.venv/bin/python add_music.py
```

اجرای مجدد `add_music.py` امن است: گویندگی همیشه از فایل اصلی FLAC خوانده می‌شود و موسیقی روی میکس قبلی انباشته نمی‌شود. رندر و میکس را هم‌زمان اجرا نکنید. فایل‌های موقت در `media/` نادیده گرفته می‌شوند.

برای بررسی یک فریم: `.venv/bin/python render.py --preview 16` (فایل موقت `deliverables/preview.jpg`).

## محتوا و مجوز

چهرهٔ زَروان، معماری و ساعت‌شنی نمادین‌اند؛ بازسازی مستند تاریخی یا ادعای وجود ساعت‌شنی در آیین زَروانی نیستند. تصویرها و گویندگی با هوش مصنوعی تولید شده‌اند. روایت، زَروانی‌گری را از باور همهٔ زرتشتیان متمایز می‌کند. موسیقی تألیفی و برنامه‌نویسی‌شده است، نه بازسازی موسیقی ایران باستان. فونت Vazirmatn از پروژهٔ rastikerdar/vazirmatn با مجوز SIL Open Font License استفاده شده؛ مجوز در `assets/OFL.txt` موجود است.
