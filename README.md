## طراحی نسخهٔ جدید

| زمان | صحنه | حرکت و طراحی |
| --- | --- | --- |
| 00–07 | زمان پیش از جهان | هستهٔ نور، مدارهای گسترش‌یابنده و گردش ذرات |
| 07–19 | زَروان | پرترهٔ نمادین با حرکت مستقل دوربین |
| 19–28 | روشنایی و تاریکی | تصویر مستقل و دو جریان ذرات گرم و سرد |
| 28–35 | تمایز روایت تاریخی | بازگشت به فضای کیهانی با میان‌نویس توضیحی |
| 35–43 | تصویر خیالی زَروان | بازگشت به پرتره و حرکت معکوس دوربین |
| 43–50 | گذر جهان | ویرانه‌های نمادین، رد ستارگان و ذرات شن متحرک |
| 50–56 | پرسش دربارهٔ زمان | مدارهای کیهانی و پرسش فارسی |
| 56–60 | پایان‌بندی | نام زَروان و محوشدن تصویر و صدا |

گذارها دیزالوهای نرم با منحنی حرکت هستند. در نسخهٔ تازه، خود تصویرها با مشِ پیوستهٔ ۴۰ پیکسلی به‌صورت موضعی متحرک می‌شوند: جریان چرخشی سحابی و روشنایی/تاریکی، حرکت ظریف بخش‌های ریش و پارچه، و حرکت آسمان و شن با ثابت نگه‌داشتن معماری. نواحی چهره و دست‌ها از میدان حرکت پرتره کنار گذاشته می‌شوند. این روش وارپ دوبعدیِ تصویر است، نه تولید ویدئوی مولد، حرکت کامل شخصیت یا انیمیشن سه‌بعدی.

موسیقی نسبت به نسخهٔ قبل تقویت شده (بهرهٔ پایه از 0.32 به 1.15، پیش از پردازش)، نت‌های میانی تقویت شده‌اند تا در بلندگوی گوشی بهتر شنیده شوند. خروجی صدا استریو است و سایدچین با گویندگی موسیقی را هنگام صحبت به‌آرامی کاهش می‌دهد. لیمیتر نهایی برای جلوگیری از اضافه‌بار به کار رفته است.

## بازتولید

تمام ورودی‌های لازم، شامل تصاویر فشرده‌شده و روایت FLAC، داخل `assets/` ذخیره شده‌اند.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python render.py
.venv/bin/python add_music.py
```

از ریشهٔ پروژه اجرا کنید. اسکریپت دوم را فقط یک‌بار پس از هر رندر اجرا کنید؛ اجرای دوباره روی خروجی میکس‌شده، موسیقی را تکرار می‌کند. فایل‌های موقت موسیقی در `media/` ساخته و در Git نادیده گرفته می‌شوند.

## یادداشت محتوایی و حقوقی

تصاویر و گویندگی با هوش مصنوعی تولید شده‌اند. چهرهٔ زَروان و معماری، نمادین و خیالی‌اند، نه بازسازی مستند تاریخی. زَروانی‌گری یکی از سنت‌های اندیشهٔ ایرانی است، نه باور همهٔ زرتشتیان. موسیقی تألیفی و برنامه‌نویسی‌شده است و بازسازی موسیقی ایران باستان نیست. فونت Vazirmatn از پروژهٔ rastikerdar/vazirmatn با مجوز SIL Open Font License استفاده شده؛ متن مجوز در `assets/OFL.txt` موجود است.
